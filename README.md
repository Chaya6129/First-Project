# בוט שאלות על ספר ילדים (RAG)

## הרצה
1. `pip install -r requirements.txt`
2. העתיקו `.env.example` ל-`.env` והדביקו את המפתח מ-Google AI Studio.
3. בדקו ב-AI Studio את השמות המדויקים של המודלים, ועדכנו ב-`config.py` אם צריך.
4. שימו את קובץ הספר בתיקייה `data/` (ומחקו את `data/README.txt`).
5. `streamlit run app.py`

## איפה כל החלטה נמצאת
כל ההחלטות נמצאות ב-`config.py`, מחולקות לחלק א' ולחלק ב'.

## אבחון
- בטרמינל מודפסת כל תחנה: טעינה, חלוקה, Embedding, השאלה המורחבת, הקטעים שנשלפו והתשובה.
- בממשק, "מאחורי הקלעים" מציג את השאלה המורחבת ואת הקטעים שנשלפו.
- שינוי הגדרות של חלק א' מזוהה אוטומטית, והמאגר נבנה מחדש.
