# בוט שאלות על ספר ילדים (RAG)

## שגיאות שהיו במהלך הבנייה ואיך נפתרו

### 1. שגיאת תעודת אבטחה (SSL) בעליית הבוט
**השגיאה:**
`[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed: CA cert does not include key usage extension`

**הסיבה:** החיבור לאינטרנט עובר דרך סינון שבודק את התעבורה, ולכן כל פנייה לרשת, כולל הפנייה ל-Gemini API, חתומה בתעודת האבטחה של הסינון. החל מ-Python 3.13 הבדיקה של תעודות מחמירה יותר, ותעודת הסינון חסרה שדה (key usage extension) שהגרסה החדשה דורשת. לכן Python דחה את החיבור. בדיקת הגרסה (`python --version`) הראתה Python 3.13.5.

**הפתרון:** התקנת הספרייה `truststore`, שגורמת ל-Python להשתמש במאגר התעודות של Windows, שבו תעודת הסינון כבר מותקנת, במקום בבדיקה המחמירה. נוספו שתי שורות בראש `app.py`, לפני כל ה-import האחרים:
```python
import truststore
truststore.inject_into_ssl()
```
`truststore` נוספה גם ל-`requirements.txt`. פתרון חלופי: להריץ את הפרויקט עם Python 3.12.

### 2. IndentationError ב-app.py
**השגיאה:**
`IndentationError: unexpected indent` (שורה 2)

**הסיבה:** בהוספת שורות ה-`truststore` נכנסו בהדבקה רווחים לפני השורה הראשונה של הקובץ. ב-Python רווחים בתחילת שורה הם חלק מהתחביר, ושורות ברמה העליונה חייבות להתחיל בעמודה הראשונה.

**הפתרון:** הסרת הרווחים מתחילת השורות שבראש הקובץ, כך שכל שורה מתחילה בקצה השמאלי.

### 3. הגדרות העיצוב של Streamlit לא נטענו
**התסמין:** הממשק הוצג בעיצוב ברירת המחדל הכהה, ולא בצבעים שהוגדרו ב-`config.toml`.

**האבחון:** הפקודה `streamlit config show` הראתה שהגדרות ה-`[theme]` לא נטענו: לפני כל הגדרה הופיע `#`, כלומר ערך ברירת מחדל. בדיקה עם `Get-ChildItem -Force .streamlit` העלתה שהתיקייה `.streamlit` כלל לא קיימת בתיקיית הפרויקט. Streamlit מחפש את `config.toml` רק בתוך תיקייה בשם `.streamlit` שנמצאת בתיקייה שממנה מריצים את הפקודה.

**הפתרון:** יצירת התיקייה `.streamlit` בתיקייה הראשית של הפרויקט, ויצירת `config.toml` בתוכה, עם `base = "light"` כדי לכפות בסיס בהיר. הקובץ נשמר בקידוד ASCII, כדי למנוע תו נסתר (BOM) בתחילתו. אחר כך הופעל Streamlit מחדש, כי את קובץ ההגדרות הוא קורא רק בעלייה.
